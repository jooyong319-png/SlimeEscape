## 🔴 확정 규칙 (일곱 줄)

1. 머리를 상하좌우 **한 칸씩** 옮긴다. 몸이 따라온다
2. 🔴 **중력이 있다.** 발밑이 비면 떨어진다
3. 🔴 위로 k칸 오르려면 **길이가 k+1 이상** — 짧으면 못 오른다. 먹는 순서가 저절로 강제된다
4. 조각을 먹으면 **길이 +1**. 줄어드는 건 없다
5. 🔴 **죽는 게 없다.** 벽·자기 몸에 막히기만 한다. 되돌리기 무제한
6. 🔴 **표시된 홈을 몸으로 정확히 채우면 이긴다.** 이게 전부다 — 남아도 모자라도 안 된다
7. 별(`o`)은 지나가면 먹힌다. **몸은 안 는다** — 순수한 우회 비용이다

⚠️ **나가는 문 · 심(心) · 게이트는 rev.6에서 전부 뺐다.** 이기는 조건은 6번 한 줄뿐이다
([[design-lineage]] rev.6). 옛 문서에 문 얘기가 남아 있으면 그건 낡은 것이다.

세계관은 **버려진 기계 유적 · 몸이 곧 열쇠**. 근거 전문은 `docs/design-study.html`.

## 지금 어디까지 왔나 (2026-09-02)

**🔴 1챕터는 게임으로서 돌아간다.** 튜토리얼 → 47판 → 별 → 힌트 → 판 고르기까지 이어진다.
**출시를 막는 건 글꼴 하나뿐**이다 ([[todo]]).

| 무엇 | 상태 |
|---|---|
| 판 | **1-0 ~ 1-46** · 1홈 → 2홈 → 3홈으로 넘어가며 판도 커진다. 정본은 `levels.json` |
| 튜토리얼 | **1-0** — 옆 안내판이 저절로 넘어간다. 방향키 넷부터 홈 채우기까지 |
| 별 | 깨면 1 · 별 먹고 깨면 2 · **걸음 수 커트라인**까지 지키면 3 |
| 힌트 | **종류로 3단계** — 어느 홈부터 / 첫 몇 걸음 / 지금 한 걸음 |
| 이겼을 때 | 홈이 몸을 **한 마디씩 삼킨다**. 그다음 결과 화면 |
| 겉모습 | 그레이박스지만 손봤다 — 굴처럼 보이는 지형 · 눈 달린 슬라임 |
| 소리 | 별 딸 때 하나뿐 (절차 생성) |

- 🔴 **판은 이제 "만들고 거르는" 게 아니라 "정답에서 거꾸로 짓는다"** (`tools/grow.js`).
  홈이 셋이면 무작위 생성은 **0개** 나왔다 ([[design-lineage]] rev.6-a)
- 🔴 실측이 처음 나왔다 — **힌트 없이 30~35분, 보면 20분** ([[playtests]] 08-31)
- 🔴 *"처음에 뭘 하라는 건지 모르겠다"*가 두 명 중 둘 → 튜토리얼을 **판으로** 만들었다
- 🔴 *"쉽다가 갑자기 팍 어려워진다"* → 판을 47개로. **길이가 아니라 계단을 없애려던 것**
- ⚠️ **난이도 도장이 낡았다.** `lost`/`tight`/`states`가 거의 0이라 정합성 검사가
  거짓 초록불을 켠다 → `node tools/hard.js --stamp` ([[todo]])
