## 확인 도구 (밤에 만든 것)

| 도구 | 무엇 |
|---|---|
| `tools/enter.ps1 [n]` | 컴파일 기다림 → Play 확인 → 개발자 키로 n판 앞으로 |
| `tools/keys.ps1 "LEFT UP Z"` | 게임에 키를 보낸다 (T=개발자모드, N/P=판 넘기기) |
| `tools/click.ps1 x y` | 창 안 비율 좌표를 누른다 (0~1) |
| `tools/shot.ps1` | Unity 창만 찍는다 |
| `tools/play.ps1` | Ctrl+P 토글 |

🔴 배운 것 셋:
- PowerShell 5.1 은 **BOM 없는 .ps1 을 ANSI 로 읽는다** → 한글이 깨져 따옴표가 어긋난다. BOM 필수
- 로그에서 찾을 표는 **아스키**로 (`[LV]`). 한글 패턴은 글자판이 어긋나 안 잡힌다
- Unity 에디터가 **F1 을 먹는다** → 개발자 모드 키로 `T` 를 하나 더 뒀다
