# 6회차 — 난이도 곡선 · 판 수

> 2026-08-28 · *2시간을 어떻게 채우나*
> 앞 회차에서 받은 것: **19방** · 요소 셋(끝나는 자리 · 머리 바꾸기 · 머리 떼기)
> 여기서 **1a/1b도 결정**한다 (1회차에서 미뤄둔 것)

---

## 🔴 먼저 — 내가 5회차에서 틀리게 잡았다

5회차 끝에 이렇게 적었다:

> *"19방이면 3~5시간이 나온다. **2시간 목표보다 길다** — 판을 줄일지 정해야 한다"*

**틀렸다.** 사장님 말씀은 이거였다:

> *"최소 2시간 **이상** 플레이 타임이 나와야 한다"*

**2시간은 최대가 아니라 최소다.** 3~5시간이면 문제가 아니라 **목표 초과 달성**이다.

## 그래서 진짜 위험은 반대쪽이다

🔴 **판이 충분히 어렵지 않아서 2시간이 안 나오는 것.**

| 판당 평균 | 19방 총합 | |
|---|---|---|
| **11~15분** (Snakebird급) | 3.5~4.7시간 | 🟢 초과 달성 |
| **6~8분** (중간) | 1.9~2.5시간 | 🟢 겨우 달성 |
| **3~4분** (쉬움) | **1~1.3시간** | 🔴 **미달** |

**→ 우리가 맞춰야 할 숫자는 판당 평균 6~7분이다.**

**[판단]** 그리고 이게 어려운 이유는 1회차에서 이미 적었다:
*"쉬운 판 50개는 노동이지만, 어려운 판 10개는 재능이다."*
**설계를 처음 하는 사람이 만든 판은 3~4분짜리가 나오기 쉽다.**

---

## 🔴 그런데 솔버는 난이도를 못 잰다

이걸 먼저 인정하고 가야 한다.

솔버가 아는 것: **최단 몇 수인가 · 해가 유일한가 · 상태가 몇 개인가**
솔버가 모르는 것: 🔴 **사람이 몇 분 걸리는가**

*"몇 분"*은 **틀린 길이 얼마나 그럴듯해 보이는가**로 정해진다.
최단 12수짜리가 30초에 풀릴 수도, 15분 걸릴 수도 있다.

### 그래도 솔버가 줄 수 있는 대리 지표 넷

| 지표 | 뜻 | 높으면 |
|---|---|---|
| **최단 수** | 정답 길이 | 대체로 어렵다 (약한 상관) |
| **도달 가능 상태 수** | 탐색 공간 크기 | 헤맬 여지가 크다 |
| 🔴 **막다른 상태 비율** | *더 못 움직이는 상태 / 전체 상태* | **자주 막힌다 = 되돌리기를 자주 쓴다** |
| **최단해 유일성** | 정답이 하나뿐인가 | 대충 해선 안 풀린다 |

**[판단] "막다른 상태 비율"이 우리가 아직 안 재고 있는 지표다.**
이게 낮으면 *"아무렇게나 가도 대충 풀리는 판"*이고, 그런 판은 3분짜리다.

⚠️ **이건 재봐야 안다** — 이 비율과 실제 풀이 시간이 상관있는지는 사람이 풀어봐야 확인된다.
다만 **없는 것보단 낫고, 만드는 비용이 거의 0이다** (이미 전체 상태를 훑고 있으니).

---

## 🔴 판을 "7분짜리"로 만드는 법

**[판단]** 판을 키우면 시간이 늘긴 하는데 **지루하게** 는다. 그건 노동이지 퍼즐이 아니다.
진짜 어려움은 딴 데서 온다.

| 방법 | 효과 | 위험 |
|---|---|---|
| 🔴 **그럴듯한 오답을 심는다** | **가장 크다.** 눈에 먼저 들어오는 길이 막다른 길 | 잘못하면 심술궂게 느껴진다 |
| **끝나는 자리(①)를 멀리 둔다** | 경로 전체를 거꾸로 계획해야 함 | — |
| **조각을 먹는 순서가 하나뿐이게** | 순서 탐색이 생긴다 | 너무 조이면 시행착오만 남는다 |
| 판을 키운다 | 확실하지만 **지루하게** 는다 | 🔴 마지막 수단 |
| 요소를 겹친다 | 조합 폭발 | 후반에만 |

🔴 **핵심은 첫 번째다.** *"딱 봐도 저 길인데"* 하고 갔더니 두 칸 남기고 막히는 것 —
그때 사람은 **처음부터 다시 생각한다.** 그게 5분을 만든다.

**[판단]** 그래서 판 설계의 실제 작업은 *"정답 만들기"*가 아니라
**"그럴듯한 오답 심기"**다. 솔버는 정답만 검증하지 오답의 매력도는 못 잰다 —
**여기가 사람이 해야 하는 부분이다.**

# 난이도 곡선 — 세 가지 모양

## 안 A — 계단 (계속 올라간다)

```
난이도 │              ▄▄▄▄
       │         ▄▄▄▄
       │    ▄▄▄▄
       │▄▄▄▄
       └──────────────────  방
```

- 🟢 단순하고 만들기 쉽다
- 🔴 **숨 돌릴 곳이 없다.** 후반에 계속 어려우면 지친다
- 🔴 막히면 거기서 끝 (갈래로 완화되긴 한다)

## 안 B — 톱니 (오르내린다) ⭐ 추천

```
난이도 │        ▄▖   ▄▄▖  ▄▄▄▖
       │   ▄▖  █ ▌  ██ ▌ ███ ▌
       │▄▖ █▌  █ ▌  ██ ▌ ███ ▌
       └──────────────────────  방
        도입 활용 시험 도입 활용 …
```

**새 요소를 도입하는 방은 쉽게, 활용하는 방은 어렵게.** 그리고 가끔 확 쉬운 방.

- 🟢 **요소 로드맵과 저절로 맞는다** (5회차에서 이미 도입/활용을 나눴다)
- 🟢 도입판이 쉬우면 **요소를 확실히 배운다**
- 🟢 어려운 판 뒤의 쉬운 판이 **보상처럼 느껴진다**
- 🟡 총 시간이 A보다 짧아진다 (쉬운 판이 섞이니까)

## 안 C — 앞이 어렵고 뒤가 쉽다 (역방향)

- 🔴 말이 안 된다. 배우기 전에 어려운 건 그냥 나쁜 게임

## 🔴 구체안 — 19방 시간 배분

**안 B(톱니)로 짠 표.** 목표는 **총 120분 이상**.

| 방 | 무엇 | 난이도 | 목표 시간 |
|---|---|---|---|
| 1 | 이동·채우면 열림 (실패 불가) | ▁ | 30초 |
| 2 | 먹으면 길어짐 | ▁ | 1분 |
| 3 | 먹는 순서 | ▂ | 2분 |
| 4 | **처음 막힘 → `Z` 배움** | ▂ | 2분 |
| 5 | 갈림길 | ▁ | 1분 |
| **6** | **① 끝나는 자리 도입** | ▂ | 2분 |
| 7 | ① 활용 | ▄ | 5분 |
| 8 | 갈래 (쉬운 길 / 어려운 길) | ▃/▅ | 4분 |
| **9** | **② 머리 바꾸기 도입** | ▂ | 3분 |
| 10 | ② 활용 | ▄ | 6분 |
| 11 | ② 활용 — *언제 바꿀까* | ▅ | 8분 |
| **12** | **①+② 중간 시험** | ▆ | 11분 |
| 13 | 갈래 (숨 돌리기) | ▃ | 4분 |
| **14** | **③ 머리 떼기 도입** | ▂ | 4분 |
| 15 | ③ 활용 | ▄ | 8분 |
| 16 | ③ 활용 — 어느 머리로 끝낼까 | ▅ | 11분 |
| **17** | 셋 다 | ▇ | 16분 |
| **18** | 셋 다 — 마지막 난관 | ▇ | 20분 |
| 19 | 마무리 (쉽게, 유적 밖으로) | ▂ | 3분 |
| | | | **총 111분** |

🔴 **111분. 2시간에 9분 모자란다.**

### 모자란 9분을 메우는 세 가지 방법

| 방법 | 얻는 시간 | 평가 |
|---|---|---|
| **A. 갈래를 하나 더** (2방 추가 → 21방) | +8~10분 | 🟢 **추천.** 막힘 대응도 같이 는다 |
| B. 17·18방을 더 어렵게 | +5~10분 | 🟡 이미 제일 어렵다. 더 조이면 벽이 된다 |
| C. 예비 요소(큰 조각)를 12방쯤에 끼운다 | +6~8분 | 🟡 요소가 넷이 되어 5회차 계산이 깨진다 |

**[판단] A를 권한다.** 갈래는 **시간도 늘리고 막힘도 푼다.** 두 마리다.
→ **최종 21방 · 약 120분.**

⚠️ 다만 이 표는 **전부 추정이다.** 실제 시간은 사람이 풀어봐야 안다.
**[판단]** 그래서 실무적으로는 이렇게 해야 한다:
🔴 **판 5개를 만들고 사람 3명에게 풀려서 실제 시간을 잰다.**
평균이 목표의 절반이면 계획 전체를 다시 짠다. **처음 5개에서 알 수 있다.**

# 🔴 1a / 1b 결정

1회차에서 미뤄둔 것. 이제 자료가 모였으니 정한다.

| | **1a 지나가면 길어진다** | **1b 먹으면 길어진다** |
|---|---|---|
| 경쟁 (1회차) | 🔴 **Snake Coil이 두 달 전 출시** · Shy Snake · One Line | 🟢 덜 붐빔 (Dotsnake 정도) |
| 세계관 (2회차) | 🟡 "열쇠 조각"이 필요 없어짐 | 🟢 **조각 개수 = 필요한 길이.** 보자마자 안다 |
| 튜토리얼 (4회차) | 🟡 길이를 알려줄 단서가 없다 | 🟢 **조각을 세면 목표 길이를 안다** |
| 요소 (5회차) | 🟡 셋 다 되긴 함 | 🟢 셋이 1b 전제로 짜였다 |
| **판 만들기** | 🟢🟢 **기계가 생성·검증 가능** | 🟡 조각 배치까지 풀어야 한다 |
| 사장님 선호 | | 🟢 *"개인적으론 이게 좋다"* |

## 🔴 결정: **1b (먹으면 길어진다)**

**근거 셋:**

1. **1a의 유일한 큰 장점(자동 생성)이 요소를 넣으면 사라진다.**
   요소 셋(끝나는 자리·머리 바꾸기·머리 떼기)이 들어가면 생성기도 그만큼 복잡해진다.
   그리고 **판이 21개뿐이면 손으로 만들어도 된다** — 60개였다면 얘기가 달랐다
2. **1a는 두 달 전에 같은 게임이 나왔다.** 정면으로 겹친다
3. 🔴 **1b는 "조각 개수 = 필요한 길이"라 판을 보자마자 할 일을 안다.**
   대사가 없는 게임에서 이건 아주 큰 이점이다 (4회차 참고)

**[판단]** 사장님 직감이 조사 결과와 같은 곳을 가리켰다.

## ⚠️ 머리 떼기(③)의 검증 비용 — 판 수에 미치는 영향

5회차에서 넘긴 숙제다.

머리를 떼면 몸이 여러 조각이 되고, 솔버 상태가 *"여러 사슬 + 어느 게 활성인가"*가 된다.
**상태 수가 곱으로 늘어난다.**

### 완화안 셋

| 안 | 방법 | |
|---|---|---|
| **A** | ③이 나오는 판(14~18방)은 **판을 작게** 만든다 (20×12를 다 안 쓰고 12×8쯤) | 🟢 추천. 화면 크기는 그대로 두고 **벽으로 막아** 실제 공간만 줄인다 |
| B | ③을 판당 **한 번만** 쓸 수 있게 제한 | 🟢 상태가 크게 줄고, **결정도 무거워진다**(한 번뿐이니) |
| C | 검증을 포기하고 손으로만 확인 | 🔴 원칙 2 위반 |

**[판단] A와 B를 같이 쓴다.**
🔴 특히 **B는 제약이 아니라 설계상 이득이다** — *"딱 한 번 뗄 수 있다면 어디서 뗄까"*가
그 자체로 좋은 질문이다.

## 이 회차의 결론

| | |
|---|---|
| **판 수** | **21방** (갈래 3번 포함) |
| **총 시간** | 약 **120분** — 2시간 목표 달성 |
| **곡선** | **톱니** — 도입은 쉽게, 활용은 어렵게, 가끔 숨 돌리기 |
| **맞춰야 할 숫자** | 🔴 **판당 평균 6~7분** |
| **1a/1b** | 🔴 **1b 확정 (먹으면 길어진다)** |
| **머리 떼기** | 판당 **한 번만** + 그 판들은 작게 |
| **새 지표** | **막다른 상태 비율** — 솔버에 추가할 것 |

## 🔴 가장 큰 위험 (다시 적어 둔다)

**판이 충분히 어렵지 않을 위험.**
솔버는 정답만 검증하지 *"오답이 얼마나 그럴듯한가"*는 못 잰다.
**그건 사람이 만들어야 하고, 처음 해보는 일이다.**

→ **판 5개를 만들어 사람 3명에게 풀려 보는 것**이 이 계획 전체를 검증한다.
평균이 3분이면 21방으로도 2시간이 안 나온다. **거기서 알게 된다.**
