# 3회차 — 게임 구성

> 2026-08-28 · *판들을 어떻게 엮을 것인가*
> 앞 회차에서 받은 것: 세계관 **A(열쇠·유적)** · 판 **10~15개(어렵게)** 쪽이 유리

---

## ⚠️ 먼저 — 브리프와 부딪히는 곳 둘

2회차 추천안을 쓰려면 브리프 §6 **안 할 것 목록**과 충돌한다. 정직하게 짚고 간다.

### 충돌 1 — "열쇠 · 문" 금지

목록에 이렇게 적혀 있다:

> *"**아이템 · 스위치 · 열쇠 · 문** — 난이도는 지형에서만"*

**[판단] 이건 뜻이 다르다.**

- 금지하려던 것: **주워서 쓰는 아이템으로서의 열쇠** (열쇠를 먹고 → 문이 열린다는 **새 규칙**)
- 2회차의 열쇠: **은유일 뿐이다.** 몸이 열쇠고, 문은 *"클리어했다"*의 그림이다. **새 규칙이 없다**

→ 목록에 **한 줄을 붙여 구분**해야 한다:
> *"금지하는 건 **규칙을 늘리는 아이템**이지, **규칙을 설명하는 그림**이 아니다."*

### 충돌 2 — "월드맵" 금지

> *"레벨 에디터 · 월드맵"* 금지

이 회차가 다루는 게 바로 그거다. **[판단] 이 금지는 유효하다** — 아래 안 C에서 그대로 확인된다.
다만 *"어떻게 판을 엮느냐"* 자체는 정해야 하니, 월드맵이 아닌 방법들을 본다.

🔴 어제 이미 적어둔 것과 같은 문제다: **안 할 것 목록이 "난이도를 만드는 것"과
"스코프를 부풀리는 것"을 구분 못 하고 있다.** 7회차에서 목록을 다시 쓸 것.

## 이 회차가 답해야 할 질문 넷

| # | 질문 | 왜 중요한가 |
|---|---|---|
| 1 | 판을 **어떤 순서로** 만나나 | 난이도 곡선이 여기 달렸다 |
| 2 | 🔴 **막히면 어떻게 하나** | 어려운 판 10~15개면 **반드시 막힌다.** 여기서 끄면 끝이다 |
| 3 | 켜자마자 **몇 초 만에** 첫 걸음을 떼나 | `success-state.md`에 *"3초"*로 적어 뒀다 |

2번이 제일 무겁다. **판 10~15개짜리 어려운 퍼즐 게임에서 막힘 대응은 선택이 아니다.**

# 안 A — 일직선 · 방 하나 풀면 다음 방

## 어떻게 보이나

메뉴가 없다. 켜면 첫 방이다. 홈을 채우면 **문이 열리고 화면이 옆으로 밀려** 다음 방이 나온다.
유적을 계속 **더 깊이** 들어간다.

## 채점

| | |
|---|---|
| 순서 | 🟢 완전히 통제된다. 난이도 곡선을 정확히 설계할 수 있다 |
| 🔴 **막힘** | 🔴 **치명적이다.** 5번 방에서 막히면 **게임이 거기서 끝난다** |
| 3초 | 🟢 최고다. 켜면 바로 게임 |
| 비용 | 🟢 제일 싸다. 화면이 하나도 안 는다 |
| 세계관 | 🟢 *"깊이 들어간다"*가 유적과 완벽히 맞는다 |

**[판단]** 막힘만 아니면 이게 정답이다. 그런데 그 하나가 치명적이다.

# 안 B — 목록/격자 선택 화면

## 어떻게 보이나

켜면 판 목록(격자 12칸). 깬 것은 표시. 아무거나 골라 들어간다.

## 채점

| | |
|---|---|
| 순서 | 🟡 순서를 강제 못 한다. 3번을 안 풀고 7번을 열면 요소를 못 배운 채 만난다 |
| 막힘 | 🟢 다른 걸 하면 된다 |
| 3초 | 🟡 화면을 한 번 거친다 |
| 비용 | 🟢 싸다 (격자 하나) |
| 세계관 | 🔴 **죽는다.** 유적을 걷다가 갑자기 메뉴가 뜬다 |

**[판단]** 안전한 선택이지만 **세계관을 버리는 대가**를 치른다.
그리고 판이 10~15개뿐이면 **선택 화면이 오히려 초라해 보인다** (12칸짜리 격자는 휑하다).

# 안 C — 마리오식 월드맵

## 어떻게 보이나

지도 위 노드를 걸어 다니며 판에 들어간다.

## 채점

| | |
|---|---|
| 순서 | 🟢 통제 가능 |
| 막힘 | 🟢 옆길로 샐 수 있다 |

| 비용 | 🔴 **비싸다.** 지도 아트 + 이동 + 노드 상태 관리. **게임 하나를 더 만드는 것** |
| 세계관 | 🟡 유적 지도는 어울리는데, 유적을 **위에서 내려다보는** 시점이 생긴다 |

마리오는 판이 90개라 지도가 필요했다. 우리는 화면 한 장에 다 들어간다.
브리프의 금지가 여기서는 옳다.

# 🔴 안 D — 갈라지는 유적 (추천)

## 한 줄

> **일직선인데, 가끔 문이 둘 열린다.**

## 어떻게 보이나

기본은 안 A와 같다 — 메뉴 없이 방에서 방으로. 그런데 **몇 방마다 갈림길**이 나온다.
방 하나를 풀면 **문이 두 개** 열리고, 둘 중 아무 쪽이나 갈 수 있다.
두 길은 서너 방 뒤에 **다시 합쳐진다.**

```
      ┌── 4a ── 5a ──┐
1 ─ 2 ─ 3            6 ─ 7 ─ ...
      └── 4b ── 5b ──┘
```

## 이게 푸는 것

🔴 **막힘 대응이 세계관 안에서 해결된다.**
4a에서 막히면 **되돌아가 4b로 간다.** 메뉴를 열 필요가 없다.
*"다른 길로 돌아간다"*는 유적 탐험 그 자체다.

그리고 합류 지점 덕분에 **순서 통제도 유지된다** — 6번 방에 도착한 사람은
4a든 4b든 **같은 것을 배우고 왔다.**

## 채점

| | |
|---|---|
| 순서 | 🟢 갈래 안에서만 자유. 합류점 기준으로 곡선을 설계할 수 있다 |
| 🔴 **막힘** | 🟢 **해결된다.** 그것도 세계관을 안 깨고 |
| 3초 | 🟢 메뉴가 없다 |
| 비용 | 🟡 A보다 약간 비싸다 — **판이 갈래만큼 더 필요**하다 |
| 세계관 | 🟢 유적이 갈라지는 건 당연하다 |

## ⚠️ 대가

**판이 더 필요하다.** 갈래를 두 번 넣으면 판이 4개 더 든다.
판 10~15개 계획이 **14~19개**가 된다.

**[판단] 그래도 낼 만한 값이다.** 막힌 사람을 잃는 것보다 판 4개 만드는 게 싸다.

그리고 **갈래는 난이도 조절판으로도 쓸 수 있다** —
한쪽은 쉽고 한쪽은 어렵게 만들면 사람이 알아서 자기 수준을 고른다.
(합류하니까 어느 쪽으로 가도 진도는 같다)

# 안 E — "돌아갈 수 있는 일직선" (안 D의 값싼 판)

갈래를 안 만들고, 대신 **이미 지나온 방으로 되돌아갈 수 있게**만 한다.
막히면 뒤로 가서 쉬거나 다시 풀어볼 수 있다.

- 🟢 판이 안 늘어난다
- 🔴 **막힘을 못 푼다.** 뒤로 가봐야 이미 푼 방이라 할 게 없다

**[판단]** 이것만으로는 부족하다. **D의 대안이 아니라 D에 얹을 것**이다
(갈래로 갔다가 돌아올 수 있어야 하니 어차피 필요하다).

## 🔴 추천: **D — 갈라지는 유적**

일직선의 장점(메뉴 없음·몰입·순서 통제·싸다)을 거의 다 지키면서
**유일한 치명적 약점인 막힘을 세계관 안에서 푼다.**

### 구체안

- **방 12~16개**, 갈래 두 번 (각 갈래는 2~3방)
- 갈래 하나는 **쉬운 길**, 하나는 **어려운 길**. 합류점은 같다
- 문을 열면 **화면이 밀려** 다음 방 (로딩·전환 화면 없음)
- 갈림길에서는 **문 두 개가 나란히** 열린다. 고르는 게 조작이 아니라 **동선**이다
  (걸어 들어가는 쪽이 선택)
- **이미 지나온 방으로 되돌아갈 수 있다** (안 E를 얹는다)
- 마지막 방을 풀면 **유적 밖으로 나온다** = 엔딩

### 진행 저장

방 번호 하나만 저장하면 된다. 갈래를 어디로 갔는지도 같이.
`PlayerPrefs` 수준으로 충분하다. **[판단] 이건 이미 구현돼 있던 것과 같은 수준이다.**

## ⚠️ 이건 재봐야 안다

- **갈래가 실제로 막힘을 풀어주는지**는 사람이 막혀봐야 안다.
  어떤 사람은 갈래가 있어도 그 방을 붙잡고 안 넘어간다
- **문이 둘 열렸을 때 "골라도 된다"를 이해하는지** — 말 없이 전달돼야 한다.
  4회차(튜토리얼)에서 다룰 것
