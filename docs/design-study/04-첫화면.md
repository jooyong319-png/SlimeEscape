# 4회차 — 첫 화면 · 튜토리얼

> 2026-08-28
> 앞 회차에서 받은 것: 구성 **D(갈라지는 유적)** — **메뉴가 없다. 켜면 바로 1번 방.**
> 그래서 이 회차의 질문이 둘로 갈렸다:
> **① 제목과 시작 버튼을 어디 두나  ② 메뉴가 없는데 어디서 가르치나**

---

## 먼저 — 가르쳐야 할 것이 몇 개인지 세어 본다

| # | 가르칠 것 | 스스로 알 수 있나 | 모르면 |
|---|---|---|---|
| 1 | 방향키로 머리가 움직인다 | 🟢 대부분 시도한다 | — |
| 2 | 몸이 따라온다 | 🟢 한 걸음 떼면 보인다 | — |
| 3 | 조각을 먹으면 길어진다 | 🟢 한 번 먹으면 안다 | — |
| 4 | **홈을 정확히 채우면 문이 열린다** | 🟡 *"정확히"*가 안 보인다 | 목표를 모른다 |
| 5 | 자기 몸에 부딪히면 못 간다 | 🟢 해보면 안다 (안 죽으니 안전) | — |
| 6 | 🔴 **되돌리기(Z)** | 🔴 **절대 모른다** | **막히면 끈다** |
| 7 | 갈림길에서 골라도 된다 | 🟡 문이 둘이면 짐작은 한다 | 한쪽만 시도 |

**[판단] 진짜 문제는 4번과 6번, 특히 6번이다.**

🔴 **되돌리기를 모르면 막혔을 때 게임을 끕니다.** 퍼즐 게임에서 이건 치명적이다.
1·2·3·5는 놔둬도 알아서 배운다.

# 1부 — 첫 화면

## 안 A — 제목 화면이 아예 없다

켜면 바로 1번 방. 게임 이름은 스토어 페이지와 창 제목에만 있다.

| | |
|---|---|
| 3초 | 🟢 **0초다.** 켜면 게임 |
| 몰입 | 🟢 최고 |
| 비용 | 🟢 화면 0개 |
| 🔴 이름 각인 | 🔴 **게임 이름을 아무도 못 본다** |
| 다시하기·설정 | 🔴 갈 곳이 없다 |

**[판단]** itch.io에서 이름이 안 남는 건 유통상 손해다. 그리고 설정(소리 끄기)이 갈 데가 없다.

## 안 B — 작은 제목 화면 (제목 + "아무 키나")

| | |
|---|---|
| 3초 | 🟡 한 번 누르면 넘어감 |
| 몰입 | 🟡 유적에 들어가기 전에 표지가 하나 |
| 비용 | 🟡 화면 하나 |
| 이름 각인 | 🟢 확실하다 |

**[판단]** 무난하지만 *"메뉴 없이 바로"*라는 우리 성격이 흐려진다.

## 🔴 안 C — 제목이 첫 방 위에 겹쳐 뜬다 (추천)

**1번 방이 이미 화면에 있고, 그 위에 제목이 떠 있다.**
슬라임이 살짝 움직이고 있다(대기 애니메이션). **첫 걸음을 떼면 제목이 스르륵 사라진다.**

```
┌────────────────────────────┐
│                            │
│      S L I M E             │   ← 제목 (반투명)
│      E S C A P E           │
│                            │
│   ▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪         │
│   ▪  ●         ▨  ▪        │   ← 1번 방이 이미 여기 있다
│   ▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪         │
│                            │
│      ← ↑ ↓ →               │   ← 조작 힌트, 첫 걸음에 같이 사라짐
└────────────────────────────┘
```

| | |
|---|---|
| 3초 | 🟢 **첫 걸음이 곧 시작 버튼이다** |
| 몰입 | 🟢 화면 전환이 없다 |
| 비용 | 🟢 판 위에 글자 얹기 |
| 이름 각인 | 🟢 크게 보인다 |
| 다시하기·설정 | 🟡 아래에 작게 두거나, `Esc`로 부른다 |

**[판단] 셋 중 유일하게 잃는 게 없다.**
그리고 *"움직이면 시작"*은 이 게임의 성격을 첫 3초에 알려준다 — **버튼이 아니라 몸이다.**

⚠️ 대신 **설정(소리)은 `Esc` 창으로** 따로 둬야 한다. 그건 판 위가 아니라 오버레이로.

# 2부 — 튜토리얼

## 안 1 — 글자로 안내한다

*"방향키로 움직이세요"* / *"Z를 눌러 되돌리기"* 를 화면에 띄운다.

| | |
|---|---|
| 확실한가 | 🟢 확실하다 |
| 세계관 | 🔴 **깨진다.** 대사 금지 원칙과도 어긋난다 |
| 번역 | 🔴 언어마다 다시 |

**[판단]** 가장 안전하지만 우리가 세운 것들과 정면으로 싸운다.

## 안 2 — 판으로만 가르친다 (무언)

첫 방들을 **실패가 불가능하게** 만들어 저절로 배우게 한다.
Baba Is You · Snakebird 방식.

| | |
|---|---|
| 확실한가 | 🟡 1·2·3·5는 확실. 🔴 **6번(되돌리기)은 못 가르친다** |
| 세계관 | 🟢 안 깨진다 |
| 번역 | 🟢 필요 없다 |

**[판단]** 대부분을 해결하는데 **되돌리기 하나가 남는다.** 그게 제일 중요한 건데.

## 안 3 — 유적에 새겨진 기호로 가르친다

벽·바닥에 **고대 기호**가 새겨져 있다. 화살표, 손 모양, 되감기 표시.
말이 아니라 **그림**이고, 유적에 새김이 있는 건 자연스럽다.

| | |
|---|---|
| 확실한가 | 🟡 기호를 알아보면 확실 |
| 세계관 | 🟢 **오히려 강화된다** — 누군가 남긴 안내 |
| 번역 | 🟢 필요 없다 |
| 비용 | 🟡 기호 도트를 그려야 함 (몇 개 안 된다) |

**[판단]** 세계관과 가장 잘 맞고, 글자를 안 쓰면서 확실성을 올린다.

## 🔴 안 4 — 상황이 오면 그때 알려준다 (추천, 안 2·3에 얹는 것)

**막다른 상태가 되면** — 더 움직일 수 없거나, 조각을 다 먹었는데 홈이 안 맞으면 —
그때 **화면 구석에 `Z` 기호가 조용히 나타난다.**

🔴 **되돌리기는 "필요해지는 순간"에 가르쳐야 한다.**
처음부터 띄우면 안 읽고, 안 띄우면 막혔을 때 끈다.
**막힌 그 순간이 유일하게 배울 준비가 된 때다.**

| | |
|---|---|
| 확실한가 | 🟢 **필요한 순간에 뜨니 반드시 읽힌다** |
| 세계관 | 🟢 평소엔 안 보인다 |
| 비용 | 🟢 조건 하나 + 기호 하나 |

---

## 🔴 추천 조합: **C + (2 + 3 + 4)**

| 무엇을 | 어떻게 |
|---|---|
| 제목·시작 | **안 C** — 1번 방 위에 겹쳐 뜨고, 첫 걸음에 사라진다 |
| 이동 (1·2) | 첫 화면의 `← ↑ ↓ →` 기호 하나. 첫 걸음에 같이 사라짐 |
| 먹으면 길어짐 (3) | **판으로** — 2번 방에 조각 하나 |
| **정확히 채우기 (4)** | **판으로 + 홈의 생김새** — 아래 참고 |
| 몸에 막힘 (5) | **판으로** — 저절로 겪는다 |
| 🔴 **되돌리기 (6)** | **안 4** — 막히면 그때 `Z`가 뜬다 |
| 갈림길 (7) | **판으로** — 문 둘이 나란히, 한쪽이 명백히 쉬움 |

---

## 🔴 4번(정확히 채우기)을 어떻게 보이게 하나

이게 이 게임에서 제일 안 보이는 규칙이다. *"닿으면 되는 게 아니라 딱 맞아야 한다."*

### 방법 ① — 홈이 판 안에 파여 있다

목표 칸이 바닥에 **음각**으로 파여 있고, 몸이 들어가면 **한 칸씩 빛이 찬다.**
다 차면 문이 열린다.

- 🟢 **"몇 칸 남았는지"가 보인다** — 진행이 눈에 보이는 게 크다
- 🟢 판 안에서 끝난다 (화면 추가 없음)

### 방법 ② — 문에 홈이 새겨져 있다 (사장님의 "오른쪽에 정답")

방 끝의 **문 자체에 목표 모양이 새겨져** 있다. 판과 분리된 그림.

- 🟢 목표 모양을 **한눈에** 본다 (판 위에 흩어져 있으면 세어야 한다)
- 🟢 세계관과 완벽 (열쇠 구멍)
- 🟡 화면에 자리를 차지한다

### **[판단] 둘 다 쓴다.**

**바닥의 음각**은 *어디를* 채우는지, **문의 새김**은 *어떤 모양*인지를 말한다.
서로 다른 걸 알려주니 겹치지 않는다.

그리고 🔴 **조각 개수가 세 번째 안내**가 된다 —
*"조각이 4개니까 몸이 5칸이 되겠구나"*를 세면 알 수 있다.

## 첫 방 다섯 개가 무엇을 가르쳐야 하나

*(구체적인 판은 안 만든다 — 무엇을 가르칠지만)*

| 방 | 가르치는 것 | 설계 의도 |
|---|---|---|
| **1** | 이동 · 몸이 따라옴 · 채우면 열림 | 조각 **0개**. 홈이 몸과 같은 크기. **그냥 걸어 들어가면 열린다.** 실패 불가능 |
| **2** | 먹으면 길어진다 | 조각 **1개**. 안 먹으면 홈이 안 채워진다 — 자연히 먹게 된다 |
| **3** | 순서가 있다 | 조각 2개인데 **먹는 순서에 따라 몸 모양이 달라진다** |
| **4** | 자기 몸이 벽이 된다 | 처음으로 **막힐 수 있다** → 여기서 `Z` 기호가 처음 뜬다 |
| **5** | 갈림길 | 문 둘. 한쪽은 눈에 띄게 짧고 쉬움 |

🔴 **4번 방이 중요하다.** 거기서 처음 막히게 설계해서 **되돌리기를 안전한 곳에서 배우게** 한다.
어려운 판에서 처음 막히면 이미 늦다.

---

## ⚠️ 이건 재봐야 안다

- **`← ↑ ↓ →` 기호 하나로 조작이 전달되는지** — 안 되면 첫 방에서 아무도 안 움직인다.
  치명적이라 **제일 먼저 확인해야 할 것**이다
- **막힘 감지가 정확한지** — *"더 못 움직인다"*는 계산할 수 있지만,
  *"움직일 순 있는데 이미 틀렸다"*는 솔버가 있어야 안다.
  🟡 후자까지 잡으려면 **게임 안에 솔버가 들어가야 한다.** 비용이 크다.
  1차로는 *"완전히 못 움직임"*만 잡는 게 현실적이다
- **문에 새겨진 홈이 판 크기를 얼마나 잡아먹는지** — 20×12에서 자리가 나오는지 그려봐야 안다
