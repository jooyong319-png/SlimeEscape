## 1. 🔴 먼저 산수부터 — 제일 아픈 숫자

어제 사장님이 판 다섯을 푸신 기록:

```
b6 12.4초 · b4 14.3초 · b3 19.9초 · b5 21.3초 · b2 27.7초
```

**평균 20초.** 21방이면 **7분**이다. 목표는 **2시간.**

처음 하는 사람은 서너 배 걸리니 **30~40분.** 그래도 🔴 **3~4배가 모자란다.**

### 어디서 시간이 나오나 — 네 갈래

| 갈래 | 얻는 시간 | 값 |
|---|---|---|
| ① 방을 더 만든다 | 방당 20~60초 | 손이 든다. 선형 |
| ② 방을 더 어렵게 | 방당 몇 분 | 🔴 **어려운 판을 만드는 건 처음 하는 일** (브리프 §5) |
| ③ 한 방에 문 여럿 | 방당 ×1.5~2 | 🟢 **이미 만들었다** — 22개 퍼즐이 검증됨 |
| ④ 🔴 **길을 잃고 돌아다니는 시간** | ? | 🟢 **이번 연구의 구조가 주는 것** |

🔴 **④가 이번 연구의 진짜 값이다.** 메트로배니아는 퍼즐 시간만으로 채우지 않는다 —
*"어디로 가지"* 하고 헤매는 시간, 되돌아가는 시간, 못 연 문을 기억하는 시간이 절반이다.

다만 정직하게: **그게 재미있는 헤맴인지 지루한 헤맴인지는 사람이 해봐야 안다.**

## 2. 방이 몇 개 필요한가 — 세 안

2회차 구조(큰 고리 + 곁가지) 위에서 계산한다.

### 안 A — 21방 (브리프 MVP 그대로)

```
고리 14방 + 곁가지 3개 × 2방 = 20방 + 관문 1방
```

- 문이 방마다 1~2개 → **퍼즐 30개쯤**
- 퍼즐 30 × 40초 + 이동/헤맴 = **40~60분**
- 🔴 2시간엔 못 미친다
- 🟢 **끝낼 수 있다.** 브리프의 목표는 *"일단 끝내서 내보내기"* 다

### 안 B — 35방

```
고리 20방 + 곁가지 5개 × 3방 = 35방
```

- 퍼즐 50개쯤 → **1시간 20분 ~ 1시간 50분**
- 🟡 2시간에 가깝다
- 🔴 손이 1.7배 든다. 그리고 판마다 조각 배치를 손으로 잡아야 한다 (3회차 A-5의 대가)

### 안 C — 21방으로 내고, 나중에 늘린다

먼저 21방으로 **끝내서 내보낸다.** 반응을 보고 구역을 덧붙인다.

- 🟢 🔴 **고리 구조라 덧붙이기가 쉽다** — 곁가지를 더 뻗거나 고리 옆에 새 고리를 붙인다
- 🟢 브리프 §5의 판정(재미있는가)을 **실제 출시로** 받는다
- 🟢 게이트 7(출시)에 제일 빨리 닿는다
- 🔴 첫 출시 분량이 40~60분이라 *"짧다"* 는 말이 나올 수 있다

**판정: 🔴 C.** 이 프로젝트의 목표는 처음부터 *"일단 끝내서 내보내기"* 였다.
2시간은 **최소 목표**였지 출시 조건이 아니었고, 지금 산수로는 **한 번에 못 닿는다.**

> 🔴 다만 이건 사장님이 정하실 일이다. *"최소 2시간"* 은 사장님이 8월 27일에 내신 기준이다.
> 40~60분으로 먼저 내는 것에 동의하셔야 C가 성립한다.

## 3. 문양 엔딩 — 구조에 어떻게 앉히나

이미 정해진 것 (2026-08-28):

- 각 스테이지의 클리어 모양이 **문양 한 획**
- 다 모으면 마지막 문이 열린다
- 🔴 재봤다: 문양을 고정해도 난이도가 안 죽는다 (一 90.7% · ㅁ 76.4% · ㄱ 67.2%)
- 🔴 **7칸에서 무너진다** → 스테이지 문양은 **4~5칸**

### 고리 구조 위에 앉히면

```
곁가지 끝의 문 = 문양 한 획      ← 2회차에서 정한 "돌아올 이유"
곁가지 5개 = 획 5개
고리를 한 바퀴 돌면 마지막 문 앞에 선다 — 획이 모자라면 못 연다
```

- 🟢 🔴 **2회차·3회차·5회차가 여기서 다 만난다.** 곁가지에 갈 이유(2회차), 큰 문(3회차),
  관문 방(5회차)이 전부 "획을 모으는 것"으로 하나가 된다
- 🟢 곁가지를 안 가도 고리는 돌 수 있다 → **진행은 안 막히고, 끝은 못 본다**
- 🟢 값 0 — 새 규칙이 아니라 배치다

### 마지막 방

- 다섯 획이 합쳐진 **표식**이 마지막 문에 새겨진다 (그림)
- 🔴 다섯 획을 문자 그대로 이으면 20칸 → **검증 불가**
- → 마지막 방의 목표는 그 표식의 **핵심 5~6칸**. 시각적으로는 다 합쳐지고 검증도 산다

### 🔴 그리고 마지막 방엔 심이 없다

2026-08-28에 낸 안 C. 21방 내내 *"머리가 정해진 칸에서 끝나야"* 했는데, 마지막엔 **어디서 끝내도 된다.**

- 🟢 규칙을 더하는 게 아니라 **빼는** 엔딩. 이 프로젝트 전체 원칙과 같은 방향
- 🟢 값 거의 0 (`*`를 `=`로)
- 🔴 알아채기 어렵다 → 표현이 받쳐야 한다

## 4. 시간을 정직하게 다시 세면

안 C(21방) 기준:

| | 시간 |
|---|---|
| 퍼즐 30개 × 40초 (처음 하는 사람) | 20분 |
| 이동·헤맴·되돌아가기 | 15~25분 |
| 막혀서 다시 시도 | 10~20분 |
| **합계** | 🔴 **45분 ~ 65분** |

🔴 **2시간은 안 나온다.** 그리고 이 숫자도 낙관적이다 — 어제 평균은 20초였다.

### 2시간에 닿으려면 무엇이 필요한가

1. **방 35개 이상** (안 B) — 손이 1.7배
2. 🔴 **판이 지금보다 훨씬 어려워야 한다** — 브리프 §5가 *"판을 어렵게 만드는 건 처음 하는 일"*
   이라고 적어둔 그것. 어제 두 번 시도했고 두 번 다 지표가 틀렸다
3. 헤매는 시간이 **재미있어야** 한다 — 지루하면 그냥 이탈이다

**이 셋 중 2번이 제일 불확실하다.** 그러니 21방으로 먼저 내고 반응을 보는 게 맞다.

- 획 5개를 모으는 데 실제로 몇 분 걸리는가
- 🔴 21방을 사람이 처음부터 끝까지 하면 정말 몇 분인가 — **이건 만들어봐야만 안다**
