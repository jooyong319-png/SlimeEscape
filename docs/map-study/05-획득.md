# 5회차 — 능력을 얻는 방식

> 2026-08-30 · 구현 없음
> 묻는 것: 사장님이 내신 셋 — **포인트로 구매? 스테이지 깨면? 보스를 잡으면?**
> 🔴 셋 중 둘이 §6 금지 항목이다. **값을 명시한다.**

---

## 0. 전제

4회차 결론: **능력은 하나만 넣는다 (머리 바꾸기).** 나머지 잠금은 지형이 한다.

🔴 그러면 이 회차의 질문이 작아진다 — **능력이 하나면 "획득 방식"이 시스템일 필요가 없다.**
한 번 주는 걸 시스템으로 만들 이유가 없기 때문이다.

그래도 사장님이 내신 안들을 제대로 따진다. **나중에 능력을 더 넣게 되면 이 회차가 근거가 된다.**

---

## 1. 안 다섯

### 안 ㄱ — 🔴 그냥 거기 있다 (추천)

고리 반대편 어느 방에 놓여 있다. 가면 얻는다.

- 🟢 **값 0.** 시스템이 아니다
- 🟢 §6 안 건드림
- 🟢 할로우 나이트가 대부분 이 방식이다 — 능력은 **장소에 있다**
- 🟢 4회차의 배치(고리 반대편)와 그대로 맞물린다
- 🔴 얻는 순간이 밋밋할 수 있다 → **표현으로 메운다** (아래 3절)

### 안 ㄴ — 문을 N개 열면 준다

- 🟢 값 아주 작음 (센 개수만 보면 됨)
- 🟢 §6 안 건드림 (점수가 아니라 진행도)
- 🔴 **장소와 무관해진다.** 어디서 얻었는지 기억이 안 남는다
- 🔴 메트로배니아의 *"저 방에 가서 얻었다"* 가 사라진다
- **판정: ㄱ보다 나은 게 없다**

### 안 ㄷ — 포인트로 구매

조각을 먹거나 문을 열면 점수가 쌓이고, 그걸로 능력을 산다.

| | |
|---|---|
| 🔴 **§6 위반** | *"점수 · 별 3개 · 랭킹"* — 금지 |
| 🔴 **버려야 하는 것** | ① **점수 표시** 화면이 생긴다. 지금 화면은 "판 이름 · 남은 홈 · 조작"뿐인데 여기에 숫자가 붙는다. 어제 친구 검증에서 *"뭐 하는지 모르겠다"* 가 나온 게 화면 문제였다 — 더 얹는 건 반대 방향이다 |
| | ② **선택이 생긴다** = 상점 화면 · 능력 목록 · 되돌리기 불가능한 소비. 게이트 5의 *"새 시스템 금지"* 에 정면으로 걸린다 |
| | ③ **조각의 뜻이 흐려진다.** 지금 조각은 *"몸을 만드는 것"* 하나인데, *"돈"* 이 겹치면 규칙이 둘이 된다 |
| 🟢 얻는 것 | 능력이 여럿일 때 **순서를 플레이어가 고른다** |
| **판정** | 🔴 **능력이 하나면 아무 값도 없다.** 사는 게 하나뿐인 상점이다. 버린다 |

### 안 ㄹ — 보스를 잡으면

| | |
|---|---|
| 🔴 **§6 위반** | *"적 · 전투 · 죽음"* — 금지 |
| 🔴 **버려야 하는 것** | ① **"죽는 게 없다"가 무너진다.** 이건 rev.1부터 확정이던 규칙이고, 되돌리기 무제한과 한 묶음이다 |
| | ② 전투 규칙 한 벌이 통째로 필요하다 — 체력·공격·패턴. **게임이 두 개가 된다** |
| | ③ 퍼즐 게임에서 보스는 보통 **큰 퍼즐**인데, 그럼 그냥 어려운 방이지 보스가 아니다 |
| 🟢 얻는 것 | 능력을 얻는 순간이 기억에 남는다. 구역의 끝이 분명해진다 |
| **판정** | 🔴 **전투는 안 된다.** 다만 *"구역의 끝에 큰 것을 둔다"* 는 살릴 수 있다 → 안 ㅁ |

### 안 ㅁ — 🔴 **관문 방** (보스의 값싼 대체)

구역 끝에 **유난히 큰 문** 하나를 둔다. 그 구역 조각을 거의 다 써야 열린다.

- 🟢 **값 0.** 그냥 큰 문이다 — 새 규칙이 없다
- 🟢 보스가 주던 것을 대부분 준다: **구역의 끝이 분명해지고, 넘은 순간이 기억에 남는다**
- 🟢 3회차 A-5와 그대로 맞물린다 (문 크기 = 요구 조건)
- 🟢 §6 안 건드림
- 🔴 전투의 긴장은 없다. **하지만 이 게임은 원래 그런 게임이다**
- **판정: 🔴 보스 대신 이것**

## 2. 정리

| 안 | 값 | §6 | 판정 |
|---|---|---|---|
| **ㄱ 그냥 거기 있다** | **0** | 🟢 | 🔴 **추천** |
| ㄴ N개 열면 | 작음 | 🟢 | 🟡 ㄱ보다 나은 게 없음 |
| ㄷ 포인트 구매 | 🔴 큼 | ❌ 점수 금지 | 버림 — 능력이 하나면 값이 0 |
| ㄹ 보스 | 🔴 아주 큼 | ❌ 전투 금지 | 버림 |
| **ㅁ 관문 방** | **0** | 🟢 | 🔴 **보스 대신 이걸로** |

---

## 3. 얻는 순간을 어떻게 만드나

안 ㄱ의 약점은 *"밋밋하다"* 였다. §6이 컷신·대사를 금지하니 **그림과 소리로만** 메운다.

| 순간 | 표현 |
|---|---|
| 능력이 있는 방에 들어서면 | 방이 유난히 조용하다. 조각도 문도 없다 |
| 능력을 얻을 때 | 🔴 **핵의 색이 바뀐다.** 이후로 계속 그 색이다 — 말 없이 "나는 달라졌다" |
| 그 뒤 처음 쓸 때 | 짧은 소리 하나 (효과음 3종 중 하나) |
| 되돌아가서 못 열던 문을 열 때 | 그 문벽에 새겨진 홈 모양이 잠깐 빛난다 |

🔴 **핵의 색이 바뀌는 게 핵심이다.** 능력 목록도 상태창도 필요 없다 —
**내 몸을 보면 안다.** §6의 *"세계관은 그림과 소리로만"* 에 정확히 맞는다.

---

## 4. 🔴 이번 회차의 결론

```
능력은 **그냥 거기 있다** — 고리 반대편 조용한 방에
얻으면 **핵의 색이 바뀐다** (상태창 없음)
보스 대신 **관문 방** — 구역 끝의 유난히 큰 문
포인트 구매와 보스는 버린다. 값이 §6 두 줄이고, 능력이 하나면 얻는 것도 없다
```

**한 문장:**

> 🔴 **능력이 하나면 획득 방식은 시스템이 아니라 장소다.**

---

## 5. 나중에 능력을 더 넣게 되면

이 회차의 결론이 뒤집히는 조건은 하나다 — **능력이 셋 이상**이 될 때.
그때는 순서를 고르는 재미가 생기므로 ㄴ이나 ㄷ이 값을 하기 시작한다.

🔴 다만 그건 §6의 *"넷째 요소 금지"* 를 §7 절차로 뒤집은 뒤의 이야기다.
**게이트 5(21방)를 넘기 전에는 꺼내지 않는다.**

## 6. 재봐야 아는 것

- 핵 색이 바뀌는 것만으로 *"능력을 얻었다"* 가 전달되는가 — **사람이 해봐야 안다**
- 관문 방(큰 문)이 실제로 "구역의 끝"으로 느껴지는가, 아니면 그냥 어려운 방인가
- 능력을 얻기까지 몇 분이 적당한가 (너무 늦으면 그때까지 지루하다)
