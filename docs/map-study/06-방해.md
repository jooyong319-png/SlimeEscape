# 6회차 — 맵 안의 방해 요소

> 2026-08-30 · 구현 없음
> 묻는 것: 사장님 말 — *"게임 내 전투와 비슷한 걸 넣을 수도 있는 거고, 방해하는 요소가 있을 수도 있고."*
> 🔴 §6이 **적 · 전투 · 죽음**을 금지한다. 값을 명시하고, 규칙을 안 늘리는 대안을 같이 낸다.

---

## 1. 먼저 — 무엇을 원하는 것인가

*"방해 요소"* 라는 말이 원하는 건 보통 셋 중 하나다. 갈라놓고 봐야 답이 나온다.

| 원하는 것 | 진짜 이름 |
|---|---|
| ㄱ. 통로가 심심하다 | **밀도** — 걸어다니는 구간에 할 게 없다 |
| ㄴ. 긴장이 없다 | **위험** — 잃을 게 없어서 아무렇게나 눌러도 된다 |
| ㄷ. 세계가 죽어 있다 | **생기** — 움직이는 게 하나도 없다 |

🔴 셋은 **전혀 다른 문제**고, 셋 중 둘은 전투 없이 풀린다.

---

## 2. ㄱ. 통로가 심심하다 — 밀도

3회차에서 *"통로엔 조각을 두지 않는다"* 고 정했다. 그러면 통로는 정말 아무것도 없는 복도가 된다.

### 안 — 통로를 **짧은 이동 퍼즐**로

조각도 문도 없지만 **지나가는 것 자체가 조금 어렵다.** 높은 턱, 떨어지면 돌아 나와야 하는 구덩이.

- 🟢 **값 0.** 이미 있는 규칙(중력·길이)만 쓴다
- 🟢 🔴 그런데 **길이 1로 다니면 아무 데도 못 오른다.** 통로가 어려우면 아예 못 지나간다
  → 통로의 턱은 **1칸까지만.** 길이 2면 넘고, 길이 1이면 돌아간다
- 🟡 이게 실은 4회차 후보 ③(좁은 틈)의 반대쪽이다: **틈은 짧아야 지나고, 턱은 길어야 넘는다**

**판정: 🟢 이걸로 충분하다.** 통로가 심심한 건 전투가 아니라 **지형**으로 푼다.

---

## 3. ㄴ. 긴장이 없다 — 위험

*"죽는 게 없다 · 되돌리기 무제한"* 이 확정 규칙이라, 실수의 값이 0이다.

### 안 A — 적을 넣는다 (사장님 안)

| | |
|---|---|
| 🔴 §6 위반 | **적 · 전투 · 죽음** — 금지 |
| 🔴 버려야 하는 것 | ① **"죽는 게 없다"** — rev.1부터의 확정 규칙. 되돌리기 무제한과 한 묶음이다 |
| | ② **솔버가 죽는다.** 적이 움직이면 상태에 적 위치가 들어간다. 적 하나에 칸 수만큼 곱해진다 (140칸이면 140배) |
| | ③ **판 검증이 무너진다.** "풀리는가 · 최단해가 하나인가"를 못 재게 된다 — 오늘까지 이 프로젝트를 지탱한 것 |
| 🟢 얻는 것 | 긴장, 속도감 |
| **판정** | 🔴 **값이 제일 크다.** 검증을 잃는 건 오늘 손으로 그린 판 9개 중 7개가 걸러졌던 그 안전장치를 버리는 것이다 |

### 안 B — 🔴 되돌릴 수 없는 선택 (추천)

적 대신 **되돌릴 수 없는 결정**으로 긴장을 만든다. 이미 게임 안에 있다:

```
조각을 먹으면 줄어들지 않는다   ← 확정 규칙
문을 열면 몸을 두고 간다        ← 요소 ③
```

🔴 **잘못 먹으면 그 방의 문을 못 채운다.** 그게 이 게임의 "위험"이다.

- 🟢 값 0
- 🟢 되돌리기(Z)가 있으니 **벌은 아니고 되짚기**다 — *"죽는 게 없다"* 와 안 부딪힌다
- 🔴 다만 3회차에서 *"통로엔 조각을 안 둔다"* 고 정해서 실수로 먹을 일을 없앴다.
  → **문이 있는 방 안에서는** 여전히 순서를 틀릴 수 있다. 긴장은 거기 있다

### 안 C — 시간·걸음 제한

- 🔴 §6 위반 (*"시간 제한 · 걸음 수 제한"* 금지)
- 🔴 되돌리기 무제한과 정면 충돌
- **판정: 버린다**

**판정: 🔴 B.** 긴장은 이미 규칙 안에 있다. 새로 만들 게 아니라 **판 설계로 꺼내 쓰는 것**이다.

---

## 4. ㄷ. 세계가 죽어 있다 — 생기

움직이는 게 하나도 없어서 유적이 아니라 도면처럼 보인다.

### 안 — 움직이지만 규칙이 아닌 것

🔴 **게임 규칙에 아무 영향이 없는 움직임**만 넣는다.

| 무엇 | 값 |
|---|---|
| 배경에서 흐르는 빛 · 먼지 | 0 — 표현 |
| 열린 문에서 새는 빛 | 0 |
| 두고 온 몸이 아주 느리게 맥동 | 0 |
| 구역마다 다른 바람 소리 | 효과음 (마감 단계) |

- 🟢 §6의 *"세계관은 그림과 소리로만"* 에 정확히 맞는다
- 🟢 솔버와 무관하다 — 상태가 하나도 안 는다
- **판정: 🟢 이걸로 충분하다.** 생기는 규칙이 아니라 그림이 만든다

---

## 5. 🔴 이번 회차의 결론

```
"방해 요소"를 셋으로 갈랐다.

밀도  → 통로를 짧은 이동 퍼즐로 (턱은 1칸까지)      값 0
위험  → 되돌릴 수 없는 선택. 이미 규칙 안에 있다    값 0
생기  → 규칙에 영향 없는 움직임과 소리             값 0

적 · 전투 · 시간제한은 버린다.
```

**한 문장:**

> 🔴 **원하신 것 셋이 다 전투 없이 된다. 그리고 셋 다 값이 0이다.**

---

## 6. 그래도 적을 넣고 싶다면 (§7 절차용 기록)

나중에 마음이 바뀌실 수 있으니, **무엇을 버려야 하는지**만 정확히 남겨둔다.

**버릴 것 (셋 다 버려야 한다):**

1. *"죽는 게 없다 · 되돌리기 무제한"* — rev.1부터의 확정 규칙
2. **솔버 검증** — 적 하나에 상태가 칸 수만큼 곱해진다. 판이 풀리는지 확인 못 하게 된다
3. **게이트 5의 "새 시스템 금지"** — 체력·공격·패턴이 통째로 들어온다

**그러면 이 게임은 퍼즐이 아니라 액션이 된다.** 그건 다른 게임이고,
브리프 rev.0에서 *"뭐가 끝날까"* 를 기준으로 고를 때 **제일 먼저 배제한 종류**다.

## 7. 재봐야 아는 것

- 통로의 턱을 1칸으로 두면 실제로 안 심심해지는가 — **너무 사소할 수도**
- 문이 있는 방 안에서 "순서를 틀리는" 긴장이 얼마나 자주 오는가
- 배경 움직임이 퍼즐을 방해하지 않는가 (🔴 격자 게임에서 연출은 칸을 건드리면 안 된다 — 두 번 깨진 적 있음)
