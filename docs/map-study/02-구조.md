# 2회차 — 맵 구조

> 2026-08-30 · 구현 없음
> 묻는 것: **방을 어떻게 엮나. 어디를 잠그나. 왜 돌아오나. 어떻게 길을 안 잃나.**

1회차 결론에서 이어진다: 부품 여덟 중 다섯이 값 0이고, 오늘 실패한 건
**통로를 전부 잠갔기 때문**이었다. 이번 회차는 그 넷(①②③⑧)을 실제 지도 모양으로 옮긴다.

---

## 1. 그물 모양 — 다섯 안

방을 점, 통로를 선으로 놓고 모양만 비교한다. 방 20개 기준.

### 안 A — 일자 사슬 (오늘 만든 것)

```
[1]─[2]─[3]─[4]─[5]─[6]
```

- 🔴 **오늘 실패한 그것.** 선택이 없다. 갈림길이 없으니 "이쪽으로 가볼까"가 안 생긴다
- 🟢 길을 잃지 않는다. 만들기도 제일 쉽다
- **판정: 버린다.** 이건 스테이지 목록에 그림만 입힌 것이다

### 안 B — 나무 (가지)

```
        [4]─[5]
       /
[1]─[2]─[3]
       \
        [6]─[7]
```

- 🟢 갈림길이 생긴다. 막다른 가지 끝에 보상을 두면 탐험이 된다
- 🔴 **되돌아가는 길이 길다.** 가지 끝까지 갔다가 갈림길까지 통째로 되짚어야 한다
- 🔴 지름길을 못 만든다 (고리가 없으니까)
- **판정: 부분만.** 가지는 좋되 끝을 다시 이어야 한다

### 안 C — 고리 (순환)

```
[1]─[2]─[3]
 │         │
[6]─[5]─[4]
```

- 🟢 **되돌아가는 길이 짧다.** 한 바퀴 돌면 출발점이다
- 🟢 🔴 **지름길이 저절로 생긴다** — 반대편에서 열면 길이 반으로 준다
- 🔴 고리만 있으면 밋밋하다. 어디로 가든 결국 같은 데로 온다
- **판정: 뼈대로 쓴다**

### 안 D — 격자

```
[1]─[2]─[3]
 │   │   │
[4]─[5]─[6]
 │   │   │
[7]─[8]─[9]
```

- 🟢 길이 아주 많다
- 🔴 **길을 잃는다.** 방들이 다 비슷해 보이고, 어디가 어딘지 기억이 안 된다
- 🔴 잠금을 걸어도 다른 길로 우회돼서 **막힌 느낌이 안 난다**
- **판정: 버린다.** 자유가 지나치면 방향이 사라진다

### 안 E — 🔴 고리 + 가지 (추천)

```
              [곁가지]
                 │
        [2]─────[3]
       /            \
    [1]              [4]      ← 큰 고리 하나
       \            /
        [6]─────[5]
                 │
              [곁가지]
```

- **큰 고리 하나**를 뼈대로 두고, 거기서 **짧은 곁가지**를 뻗는다
- 🟢 고리라서 되돌아가기가 짧다 (C의 장점)
- 🟢 곁가지 끝에 보상을 둬서 탐험이 생긴다 (B의 장점)
- 🟢 격자처럼 헷갈리지 않는다 — **"고리 위 어디쯤"** 으로 위치가 기억된다
- 🔴 곁가지가 길면 B의 단점이 그대로 돌아온다 → **곁가지는 방 2~3개까지**
- **판정: 🔴 이걸로 간다**

> 근거: 할로우 나이트의 초반부(교차로를 중심으로 사방으로 뻗고 다시 만나는 구조)가
> 이 모양이다. 🔴 **이건 내가 구조를 보고 판단한 것이고, 출처가 있는 분석은 아니다.**

## 2. 어디를 잠그나

1회차의 교훈: **통로를 전부 잠그면 자유가 0.** 그럼 얼마나 잠가야 하나.

### 잠금 비율 — 세 안

| 안 | 잠긴 통로 비율 | 느낌 | 판정 |
|---|---|---|---|
| 전부 잠금 | 100% | 🔴 스테이지 목록. **오늘 실패** | 버림 |
| 절반 | ~50% | 갈 때마다 막힘. 답답하다 | 🔴 위험 |
| **일부만** | **20~30%** | 대부분 걸어다니고 가끔 막힌다 | 🟢 **추천** |

방 20개에 통로 24개(고리+곁가지)라면 **잠긴 문은 5~7개**. 나머지는 그냥 뚫려 있다.

### 어디에 잠금을 거나 — 원칙 넷

1. 🔴 **첫 방에서 보이는 곳에 하나.** 시작하자마자 *"저긴 못 가네"* 를 심는다.
   1회차 ③의 핵심은 "못 연다"가 아니라 **"봤다"** 였다
2. **고리를 끊는 자리에 하나.** 그걸 열면 한 바퀴가 완성되고 되돌아가기가 반으로 준다 = 지름길
3. **곁가지 입구에.** 곁가지는 안 가도 되니까 — 잠가도 진행이 안 막힌다
4. 🔴 **막다른 길에는 안 건다.** 열었는데 아무 데도 안 통하면 허탈하다

### 잠금의 종류 — 세 안

| 안 | 무엇이 여나 | 값 | 판정 |
|---|---|---|---|
| **문벽** (오늘 만든 것) | 그 방의 홈을 채운다 | 0 — 이미 있다 | 🟢 기본 |
| **능력 잠금** | 그 능력이 있어야 지나간다 | 능력 시스템 필요 | 4회차에서 |
| **길이 잠금** | 몸이 k칸 이상이어야 오른다 | 🟢 **0 — 이미 규칙** | 🔴 3회차의 숙제 A와 직결 |

🔴 **세 번째가 공짜다.** 높은 턱을 하나 두면 그게 곧 잠금이다. 문도 벽도 필요 없다.
다만 요소 ③(문을 열면 길이 1로 돌아감) 때문에 **길이를 들고 다닐 수 있느냐**에 달렸다 → 3회차.

## 3. 왜 돌아오나

되돌아올 이유가 없으면 고리도 곁가지도 장식이다. 이유를 만드는 안 넷.

### 안 ㄱ — 지금은 못 여는 문을 보여준다

제일 고전적이고 값이 0이다. 지나가면서 봤던 문벽이 나중에 열린다.

- 🟢 문벽이 이미 있다. 공짜
- 🔴 **무엇이 생기면 열리는지**를 플레이어가 알아야 한다. 안 그러면 그냥 벽이다
  → 문벽에 **그 문이 요구하는 홈 모양을 새겨둔다**. 말 없이 알려주는 법

### 안 ㄴ — 조각이 남아 있다

문을 채우고 남은 조각이 방에 그대로 있다. 다음에 다른 문을 채우러 올 때 쓴다.

- 🟢 값 0 — 이미 그렇게 돈다 (먹은 조각은 안 돌아온다)
- 🔴 **한 번 먹으면 끝**이라 "다시 올 이유"가 아니라 "미리 계획할 이유"다. 성격이 다르다

### 안 ㄷ — 조각이 다시 자란다

시간이 아니라 **방을 떠났다 오면** 다시 있다.

- 🟢 되돌아오는 게 실제로 쓸모 있어진다. 길이를 다시 만들 수 있다
- 🔴 **솔버 상태가 는다** — 조각이 "먹음/안 먹음"이 아니라 방마다 리셋된다.
  🔴 얼마나 느는지는 **재봐야 안다**
- 🔴 되돌리기(Z)와 어떻게 맞물리는지 정해야 한다
- 3회차 숙제 A의 후보 A-4가 이것이다

### 안 ㄹ — 🔴 표식을 모은다 (문양 엔딩과 연결)

곁가지 끝에 **문양 한 획**이 있다. 다 모아야 마지막 문이 열린다.

- 🟢 곁가지에 갈 이유가 생긴다 (안 가도 진행은 되지만 끝은 못 본다)
- 🟢 🔴 **이미 정한 엔딩과 그대로 맞물린다** (문양을 모아 마지막 문)
- 🟢 값 0 — 새 규칙이 아니라 "곁가지 끝의 문 = 획"이라고 정하는 것뿐
- **판정: 🔴 ㄱ + ㄹ 을 기본으로. ㄷ은 3회차에서 A와 같이 판단**

## 4. 길을 안 잃게

§6이 월드맵을 금지한다. 지도 없이 위치를 기억하게 하는 법.

### ① 🔴 두고 온 몸 (1회차에서 건진 것)

연 문마다 내 몸이 굳어 박혀 있다. **지나온 자리가 지형에 남는다.**

- 🟢 지도가 아니라 세계 그 자체다. §6을 안 건드린다
- 🟢 *"여긴 왔던 데"* 가 한눈에 온다
- 🔴 **안 연 문에는 아무것도 안 남는다.** 지나가기만 한 방은 표시가 없다
  → 아래 ②③으로 메운다

### ② 구역마다 색을 다르게

고리를 서너 구역으로 나누고 바닥·벽 색을 바꾼다.

- 🟢 값이 거의 0 (색만 바꾼다). §6의 "세계관은 그림과 소리로"에 정확히 맞는다
- 🟢 *"파란 구역 어디쯤"* 으로 기억된다

### ③ 방마다 생김새를 다르게

- 🟢 값 0 — 판을 만들 때 신경 쓰는 것뿐
- 🔴 무작위 생성기로 뽑으면 다 비슷해진다. **손이 들어가야 한다**

### ④ 지도 화면

- 🔴 §6 금지. **넣으려면 버릴 것을 적어야 한다**
- 값: 화면 하나 + 방 배치 + 위치 기억. 그리고 그레이박스에선 *"네모 20개가 선으로 이어진 그림"*이다
- **판정: 게이트 5(분량) 이후로. 방이 다 있고 아트가 붙을 때 다시 꺼낸다**

---

## 5. 🔴 이번 회차의 결론

```
모양   : 큰 고리 하나 + 짧은 곁가지 (방 2~3개까지)
잠금   : 통로의 20~30%만. 첫 방에 하나 보이게 · 고리를 끊는 자리 · 곁가지 입구
        막다른 길에는 안 건다
돌아올 이유 : 못 열었던 문(ㄱ) + 곁가지 끝의 문양 한 획(ㄹ)
길찾기 : 두고 온 몸 + 구역 색. 지도는 안 만든다
```

**한 문장:**

> 🔴 **대부분은 그냥 걸어다니고, 다섯에서 일곱 군데만 막혀 있다.**
> 막힌 자리는 시작하자마자 하나 보여준다.

---

## 6. 넘기는 것

- **길이 잠금**(2절)은 공짜인데 요소 ③과 부딪힌다 → **3회차 숙제 A**
- **능력 잠금**(2절)은 앞 방을 헐겁게 만든다 → **4회차 숙제 B**
- **조각이 다시 자란다**(3절 ㄷ) → 3회차에서 A와 함께

## 7. 재봐야 아는 것

- 방 20개 · 곁가지 4개에서 **두고 온 몸만으로 길을 안 잃는가**
- 잠금 비율 20%와 40%가 실제로 얼마나 다른가
- 고리 한 바퀴가 몇 걸음이면 "돌아가기 귀찮다"가 시작되는가 (지름길이 필요해지는 지점)
- 🔴 **곁가지를 안 가고 고리만 돌면 몇 분인가** — 최단 경로 플레이 시간
