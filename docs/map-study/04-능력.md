# 4회차 — 능력

> 2026-08-30 · 구현 없음
> 묻는 것: **요소 ②③ + 다른 후보들. 각각 무엇을 열어주나. 언제 주나.**
> 그리고 🔴 **숙제 B — 능력을 주면 앞 방이 헐거워진다.**

---

## 0. 먼저 — 이미 정해진 것

- **요소 ③ 머리 떼기** = 어제 확정. 문을 열면 몸을 두고 핵만 간다. **능력이 아니라 기본 규칙**이 됐다
- **요소 ② 머리 바꾸기** = 아직 안 넣음. 이번 회차의 주인공
- 브리프 §6: **넷째 요소 금지.** 예비 1순위는 *"큰 조각 +2"*

🔴 그러니 "다양한 능력"은 **§6과 정면으로 부딪힌다.** 각 안마다 값을 적는다.

## 1. 🔴 숙제 B — 측정값부터

`tools/exp-swap.js` 로 머리 바꾸기를 켜고 지금 판 11개를 다시 풀렸다.

| | 지금 | 머리 바꾸기 있음 |
|---|---|---|
| 1-5 | 38걸음 | **26걸음** (−12) |
| b3 | 42걸음 | **33걸음** (−9) |
| b6 | 33걸음 | **26걸음** (−7) |
| b1 | 35걸음 | **29걸음** (−6) |
| … | | |
| **합계** | | 🔴 **11판 중 8판이 3~12걸음 짧아짐** |

그리고 **b2는 최단해가 1개 → 2개**가 됐다. 우리 채택 기준(*"최단해가 하나뿐일 것"*)이 깨진다.

상태 공간은 **1.0~2.7배**만 는다 — 머리 바꾸기는 칸을 안 움직이므로 싸다.

> 🔴 **결론: 능력은 반드시 순서를 설계해야 한다.** 아무 데나 주면 그 앞이 전부 헐거워진다.

## 2. 능력 후보 — 여섯

### 후보 ① 머리 바꾸기 (요소 ②) — 🔴 추천

머리와 꼬리를 맞바꾼다. 한 걸음을 쓴다.

- 🟢 **근거가 손에서 나왔다.** 사장님이 b1에서 막혔을 때 *"머리 바꾸는 키가 있어?"* 라고 물으셨다.
  책상에서 고른 게 아니라 **막혀서 떠오른 것**이다
- 🟢 중력과 안 부딪힌다 — 칸이 안 움직이니 안 떨어진다
- 🟢 상태 공간이 거의 안 는다 (1.0~2.7배)
- 🟢 §6에 안 걸린다 — **설계 연구 때부터 자리를 비워둔 요소 ②**다
- 🔴 앞 방 8개가 헐거워진다 (숙제 B)
- **무엇을 여나:** 막다른 곳에서 반대로 나올 수 있다. **좁은 통로에서 되돌아 나오기**가 된다

### 후보 ② 큰 조각 (+2)

한 번에 2칸 자라는 조각.

- 🟢 §6이 **예비 1순위**로 지정해둔 것. 뒤집는 게 아니라 예정된 카드
- 🟢 값이 아주 작다 — 조각 종류 하나 추가
- 🔴 **여는 게 없다.** 길이를 빨리 만들 뿐이라 메트로배니아 장치가 안 된다
- **판정: 능력이 아니라 판 설계 도구.** 이번 논의에선 뺀다

### 후보 ③ 좁은 틈 지나기

길이 1일 때만 지나갈 수 있는 틈. 능력이 아니라 **몸 상태**가 열쇠다.

- 🟢 🔴 **값 0.** 새 규칙이 아니라 **지형**이다 — "1칸 높이 통로"를 두면 끝
- 🟢 3회차의 A-5와 정반대 방향의 잠금이 생긴다: 큰 문은 길어야, 좁은 틈은 짧아야
- 🟢 요소 ③과 아름답게 맞물린다 — **문을 열면 길이 1이 되니, 바로 좁은 틈으로 갈 수 있다**
- **판정: 🔴 강력 추천. 능력이 아니라 지형이라 공짜다**

### 후보 ④ 벽에 붙기 (무중력 구역)

rev.5-a에서 재보고 **보류**한 것. 그 구역 안에선 안 떨어진다.

- 🔴 이미 측정했다: **어렵게 하려던 게 오히려 쉽게 만든다** (구역이 역할을 할수록 28%로 떨어짐)
- 🟢 다만 그때는 **난이도** 목적이었다. 지금은 **길을 여는** 목적이라 값이 다르다
- 🔴 규칙 +1 (§6의 넷째 요소)
- **판정: 보류 유지.** 지금 필요 없다

### 후보 ⑤ 몸을 두 조각으로 나누기

핵이 둘이 되어 각각 움직인다.

- 🟢 퍼즐 공간이 폭발적으로 는다
- 🔴 **상태 공간도 폭발한다.** 몸 하나로도 칸당 3.6배인데 둘이면 곱해진다 → 솔버가 죽는다
- 🔴 조작이 복잡해진다 (누가 움직이나)
- **판정: 버린다.** 검증을 잃는다

### 후보 ⑥ 두고 온 몸을 다시 거두기

이미 연 문에서 몸을 회수한다.

- 🟢 되돌아올 이유가 아주 강해진다
- 🔴 **문이 다시 닫힌다.** 그럼 길이 막히고, 되돌릴 수 없는 상황이 생길 수 있다
- 🔴 *"죽는 게 없다 · 되돌리기 무제한"* 과 부딪힐 위험
- **판정: 위험하다. 나중에**

## 3. 그래서 무엇을 넣나

| 후보 | 값 | 무엇을 여나 | 판정 |
|---|---|---|---|
| ① 머리 바꾸기 | 요소 ② (예정됨) | 되돌아 나오기 | 🟢 **넣는다** |
| ③ 좁은 틈 | **0 — 지형** | 길이 1일 때만 | 🟢 **넣는다** |
| ② 큰 조각 | 아주 작음 | (여는 것 없음) | 🟡 판 설계 도구로만 |
| ④ 무중력 구역 | 규칙 +1 | 오르기 | ⬜ 보류 유지 |
| ⑤ 몸 나누기 | 🔴 검증 상실 | — | ❌ |
| ⑥ 몸 회수 | 규칙 +1, 위험 | 되돌아올 이유 | ⬜ 나중에 |

🔴 **능력은 하나만 넣는다 (머리 바꾸기).** 나머지 잠금은 전부 **지형**으로 만든다:

```
큰 문     → 조각이 많은 방에 가야 열린다   (3회차 A-5)
좁은 틈   → 길이 1일 때만 지나간다        (후보 ③, 값 0)
높은 턱   → 길이가 k+1 이상이어야 오른다   (이미 규칙)
문벽      → 그 방의 문을 채워야 열린다     (이미 있음)
```

**잠금 네 종류 중 셋이 값 0이다.** 능력은 하나로 충분하다.

## 4. 숙제 B를 어떻게 다루나 — 세 안

### B-1 능력 전/후 구역을 나눈다

머리 바꾸기를 얻는 지점 이전 방은 능력 없이, 이후 방은 능력 있는 걸로 검증한다.

- 🟢 확실하다. 지금 판 11개가 그대로 산다
- 🔴 되돌아가면 앞 구역이 쉬워진다 — 고리 구조라 반드시 그렇게 된다

### B-2 🔴 헐거워지는 걸 받아들인다 (추천)

되돌아갈 때 쉬워지는 건 **메트로배니아에서 원래 보상**이다.
초반 구역을 새 능력으로 훑고 지나가는 게 성장의 증거다.

- 🟢 값 0
- 🟢 🔴 **3회차 A-5의 약점을 메운다.** A-5는 *"내가 세진 게 아니라 길이 열린 것"* 이 약점이었는데,
  능력으로 앞 구역이 쉬워지면 **세진 게 몸으로 느껴진다**
- 🔴 앞 구역을 처음 지날 때의 난이도는 능력 없이 설계해야 한다 (= B-1을 겸한다)

### B-3 능력이 여는 것만 하고 푸는 건 못 하게

문 앞에서만 쓸 수 있게 제한한다.

- 🔴 규칙이 복잡해진다. *"왜 여기선 안 되지"* 가 생긴다
- **판정: 버린다**

**판정: 🔴 B-1로 검증하고 B-2로 받아들인다.**
처음 지날 땐 능력 없이 어렵고, 돌아올 땐 능력으로 쉽다. **그게 성장이다.**

## 5. 언제 주나

2회차의 고리 구조 위에 놓으면:

```
[시작]  ← 여기서 잠긴 문을 하나 보여준다 (1회차 ③)
   │
 고리 앞쪽 (능력 없음) — 방 6~8개
   │
[🔴 머리 바꾸기]  ← 고리의 반대편. 여기까지 오는 게 1막
   │
 고리 뒤쪽 + 곁가지 (능력 있음)
   │
 되돌아가서 앞쪽의 못 열던 문을 연다  ← B-2가 여기서 값을 한다
```

- 🟢 능력이 **고리 반대편**에 있으면, 얻고 돌아오는 길이 곧 "앞 구역 다시 보기"다
- 🟢 값 0 — 배치 문제일 뿐

## 6. 🔴 이번 회차의 결론

```
능력은 **하나만** — 머리 바꾸기 (요소 ②)
나머지 잠금은 전부 지형 : 큰 문 · 좁은 틈 · 높은 턱 · 문벽  (셋이 값 0)
능력은 고리 반대편에 둔다
앞 구역은 능력 없이 검증하고, 되돌아올 때 쉬워지는 건 **보상으로 받아들인다**
```

**한 문장:**

> 🔴 **능력은 하나면 된다. 나머지는 지형이 한다.**

그리고 이게 §6을 거의 안 건드린다 — 넷째 요소를 안 만들고, 이미 비워둔 칸 하나만 채운다.

## 7. 재봐야 아는 것

- 머리 바꾸기가 **한 걸음을 쓰는지 공짜인지** — 공짜면 훨씬 강해져 판이 더 헐거워진다 (🔴 아직 안 쟀다)
- 좁은 틈(1칸 통로)이 실제로 잠금 구실을 하는가 — 길이 1로 돌아가는 순간이 많아서 **너무 자주 열릴 수도** 있다
- 능력을 얻은 뒤 앞 구역이 *"쉬워져서 기분 좋다"* 인지 *"싱거워졌다"* 인지 — **사람이 해봐야 안다**
