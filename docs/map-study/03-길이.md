# 3회차 — 몸 길이와 조각

> 2026-08-30 · 구현 없음
> 묻는 것: 🔴 **숙제 A — 길이를 들고 다닐 수 없다.**

1·2회차에서 두 번 미룬 것이 이번 본론이다. 이 연구에서 제일 어려운 문제다.

---

## 1. 문제를 정확히

### 부딪히는 두 규칙

**규칙 하나 (확정, 이 게임의 제일 큰 동사):**
> 위로 k칸 오르려면 길이가 k+1 이상. **몸이 길수록 높이 오른다.**

**규칙 둘 (어제 확정, 요소 ③):**
> 문을 열면 몸은 자물쇠에 남고 **핵만 빠져나간다. 길이 1로 돌아간다.**

🔴 **둘을 같이 두면 길이가 성장이 못 된다.** 문을 열 때마다 처음으로 돌아가니까,
*"길어져서 저기 갈 수 있게 됐다"* 가 절대 안 생긴다.

### 왜 이게 큰 문제인가

1회차에서 부품 ⑤로 적었던 것:

> **길이 자체가 능력이다 — 우리만의 것.**
> 할로우 나이트는 벽타기·이단점프로 갈 곳이 늘어난다. 우리는 그게 **이미 규칙 안에 있다.**

그리고 2회차에서 **길이 잠금**(높은 턱)이 값 0인 잠금 장치라고 적었다.
문도 벽도 안 만들고 턱만 놓으면 그게 곧 잠금이다.

🔴 **즉 이 게임에서 제일 싸고 제일 자연스러운 메트로배니아 장치가 길이인데,
요소 ③이 그걸 매번 0으로 되돌린다.**

---

## 2. 다섯 안

### 안 A-1 — 요소 ③을 버린다 (길이를 유지한다)

문을 열어도 몸이 그대로다. 자물쇠에 남는 건 **몸의 그림자**뿐(표현만).

| | |
|---|---|
| 🟢 | 길이가 곧 성장. 메트로배니아가 그대로 성립한다 |
| 🟢 | 값 0 — 규칙을 되돌리는 것뿐 |
| 🔴 | **솔버가 방 단위 검증을 잃는다.** 방에 들어올 때 길이가 3일 수도 9일 수도 있으니 모든 길이에서 풀리는지 봐야 한다 |
| 🔴 | 세계관이 무너진다. *"몸은 통행료"* 가 사라지고 문이 그냥 자물쇠가 된다 |
| 🔴 | 어제 사장님이 세 안 중에 **직접 고른 것**이 요소 ③이다 |

**판정: 값이 너무 크다.** 검증 구조는 오늘까지 이 프로젝트를 지탱한 것이다
(손으로 그린 판 9개 중 7개를 솔버가 걸렀다). 그걸 성장 하나 때문에 버리진 않는다.

---

### 안 A-2 — 문이 몸을 **일부만** 가져간다

3칸짜리 문에 길이 6으로 들어가면 3칸을 내고 **3칸이 남는다.**

| | |
|---|---|
| 🟢 | 길이가 유지된다. 성장이 생긴다 |
| 🟢 | *"몸은 통행료"* 가 그대로 산다 — 값을 치르되 전부는 아니다 |
| 🔴 | **"정확히 채운다"가 깨진다.** 지금 규칙은 남아도 모자라도 안 되는 건데, 남아도 되게 된다 |
| 🔴 | 그럼 문이 안 어렵다. 길이만 넘으면 아무 때나 열린다 |

🔴 **이 규칙의 핵심이 "정확히"다.** 그게 없으면 문은 그냥 열쇠 구멍이고, 채우기 퍼즐이 사라진다.

**판정: 버린다.** 게임의 중심을 파는 안이다.

---

### 안 A-3 — 길이 말고 **다른 것**이 자란다

길이는 매번 1로 돌아가되, **능력·표식**이 쌓인다.

| | |
|---|---|
| 🟢 | 요소 ③이 그대로 산다. 검증도 그대로 |
| 🟢 | 이미 자리가 있다 — 요소 ②(머리 바꾸기), 문양 획 |
| 🔴 | **우리만의 것(⑤)을 포기한다.** 길이가 능력인 게 이 게임의 고유함이었다 |
| 🔴 | 능력을 주면 앞 방이 헐거워진다 (숙제 B, 이미 측정됨) |

**판정: 안전하지만 밋밋하다.** 다른 게임에도 있는 구조가 된다.

---

### 안 A-4 — 조각이 다시 자란다

방을 떠났다 오면 조각이 다시 있다. 길이는 1로 돌아가지만 **다시 만들 수 있다.**

| | |
|---|---|
| 🟢 | 되돌아오는 게 실제로 쓸모 있다 (2회차 안 ㄷ) |
| 🟢 | 요소 ③이 산다 |
| 🔴 | **성장이 아니다.** 매번 다시 만드는 것이지 쌓이는 게 아니다. ⑤는 여전히 없다 |
| 🔴 | 솔버 상태가 얼마나 느는지 **재봐야 안다** |
| 🔴 | *"조각을 무한히 먹을 수 있다"* → 길이 상한이 사라져 판 설계가 어려워진다 |

**판정: 성장 문제는 못 푼다.** 편의 장치지 해답이 아니다.

---

### 안 A-5 — 🔴 **문마다 값이 다르다 + 큰 문은 나중에** (추천)

길이는 매번 1로 돌아간다. **대신 방마다 만들 수 있는 최대 길이가 다르다.**

```
초반 구역 : 조각이 적다 → 길이 4까지밖에 못 만든다 → 4칸 문만 열 수 있다
후반 구역 : 조각이 많다 → 길이 8까지 만든다 → 8칸 문이 열린다
그리고 초반에 봤던 8칸 문은 그때 못 열었다
```

🔴 **성장하는 건 길이가 아니라 "내가 갈 수 있는 곳"이다.**
그리고 그건 **방에 있는 조각이 정한다** — 내가 들고 다니는 게 아니라.

| | |
|---|---|
| 🟢 | 요소 ③이 그대로 산다. 검증도 방 단위 그대로 |
| 🟢 | **값 0.** 새 규칙이 없다. 조각을 어디에 몇 개 두느냐로만 만든다 |
| 🟢 | *"저긴 아직 못 가"* 가 생긴다 — 문 크기가 곧 요구 조건이고, **문벽에 홈 모양이 새겨져 있으니 눈으로 보인다** |
| 🟢 | 2회차의 **길이 잠금**이 이 형태로 살아난다 |
| 🔴 | 되돌아올 때 *"이제 열 수 있다"*가 **내가 세진 게 아니라 길이 열려서**다 — 성취감이 약할 수 있다 |
| 🔴 | 조각 배치가 곧 난이도 곡선이라 **손이 많이 든다** |

**판정: 🔴 이걸로 간다.**

---

## 3. 왜 A-5인가

| 안 | 요소 ③ | 방 단위 검증 | 성장 | 새 규칙 |
|---|---|---|---|---|
| A-1 유지 | ❌ 버림 | 🔴 잃음 | 🟢 강함 | 0 |
| A-2 일부만 | 🟡 반 | 🟢 | 🟢 | 🔴 "정확히"를 깸 |
| A-3 다른 것 | 🟢 | 🟢 | 🟡 흔함 | 능력 필요 |
| A-4 다시 자람 | 🟢 | 🟡 재봐야 | ❌ 없음 | +1 |
| **A-5 문마다 값** | 🟢 | 🟢 | 🟡 **길이 아닌 "갈 곳"** | **0** |

🔴 **A-5만 새 규칙 없이 셋을 다 지킨다.** 성장의 종류가 바뀌는 게 대가인데,
그 대가는 표현으로 메울 수 있다 (아래 4절).

---

## 4. A-5의 약점을 메우는 법

> *"내가 세진 게 아니라 길이 열린 것"* 이라 성취감이 약하다.

### ㄱ. 문벽에 홈 모양을 새긴다

지나갈 때 **저 문이 몇 칸짜리인지 눈에 보인다.** 그러면 나중에 조각이 많은 구역에 갔을 때
*"아, 아까 그 8칸짜리"* 가 저절로 떠오른다. 🔴 값 0이고 §6에도 안 걸린다(그림).

### ㄴ. 큰 문 뒤에는 큰 것을 둔다

곁가지 끝의 8칸 문 뒤에 **문양 한 획**이 있다. 열었을 때 얻는 게 있어야 한다.

### ㄷ. 🔴 조각을 "구역의 성질"로 만든다

구역마다 조각 밀도가 다르고, **그게 구역의 색과 함께 간다.**
*"조각이 많은 붉은 구역"* 처럼 기억되면, 큰 문을 만났을 때 어디로 가야 할지 안다.
2회차의 구역 색과 그대로 맞물린다.

## 5. 딸려 나오는 문제 — 조각을 골라 먹을 수 있나

자유롭게 돌아다니면 **지나가다 조각을 밟는다.** 그러면 원치 않게 길어진다.

| 안 | | 판정 |
|---|---|---|
| **밟으면 무조건 먹는다** | 🟢 값 0 (지금 규칙) · 🔴 지나다니는 것 자체가 위험해진다 | 🟡 |
| **골라 먹는다** (키 하나) | 🟢 자유롭게 다닐 수 있다 · 🔴 **규칙 +1**, 그리고 "줄어드는 건 없다"의 긴장이 준다 | 🔴 §6 |
| 🔴 **조각은 문 근처에만 둔다** | 🟢 **값 0.** 통로엔 조각을 안 놓으면 밟을 일이 없다 | 🟢 **추천** |

**판정: 세 번째.** 이건 규칙이 아니라 **판을 만드는 원칙**이다.

> 🔴 **통로에는 조각을 두지 않는다. 조각은 문이 있는 방에만.**

그러면 "지나가다 실수로 먹는" 일이 아예 안 생기고, 규칙도 안 는다.

## 6. 🔴 이번 회차의 결론

```
길이는 매번 1로 돌아간다 (요소 ③ 유지)
성장하는 건 길이가 아니라 **갈 수 있는 곳**이다
그리고 그건 **그 방에 조각이 몇 개 있느냐**가 정한다

문벽에는 홈 모양을 새겨 "몇 칸짜리인지" 보이게 한다
조각은 문이 있는 방에만 둔다 — 통로엔 없다
```

**한 문장:**

> 🔴 **내가 길어지는 게 아니라, 길어질 수 있는 방에 도착하는 것이다.**

## 7. 재봐야 아는 것

- 구역별 조각 밀도를 몇 단계로 나눠야 *"이제 저기 갈 수 있다"* 가 느껴지는가
- 문 크기 3칸 ~ 8칸 중 **솔버가 감당하는 상한** (이미 안다: 몸 10칸이면 290만 상태, 12칸이면 터진다 → **문은 최대 8~9칸**)
- 통로에 조각을 안 두면 통로가 심심해지지 않는가
- A-5로 갔을 때 *"세진 느낌"* 이 실제로 나는가 — 🔴 **사람이 해봐야만 안다**
