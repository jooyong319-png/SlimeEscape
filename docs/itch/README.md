## 다시 찍으려면

유니티에서 Play 를 켠 뒤 (유니티 MCP 또는 에디터 스크립트로):

```csharp
SlimeEscape.EditorTools.ShotTour.Run(
    "title,menu:1,level:1,level:7,level:14,level:21,level:28,level:36",
    "960x600", @"<저장할 폴더>\", "store");
```

찍는 동안 판 구석의 개발자 표시 「F1」 은 숨는다 (`SnakeController.HideDevHint`).
게임 창 크기 목록에 `960x600` 이 있어야 한다 — 없으면 로그에 남기고 건너뛴다.
