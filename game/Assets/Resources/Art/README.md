# 그림 넣는 곳

이 폴더에 **png**를 떨어뜨리면 그 자리가 그림으로 바뀝니다.
없는 자리는 지금까지처럼 코드가 그립니다 — **한 장씩 갈아끼워도 됩니다.**

---

## 규칙 셋

**1. 파일 이름이 곧 자리 이름입니다.** 아래 표의 이름 그대로 (소문자, 확장자 `.png`).
철자가 틀리면 **아무 말 없이 무시**됩니다. 안 바뀌면 이름부터 보세요.

**2. 정사각형으로 그리세요.** 크기는 자유입니다 — 16×16이든 64×64든 됩니다.
들여오기가 크기를 읽어서 **그림 한 장 = 판의 한 칸**으로 맞춥니다. 섞어 써도 됩니다.

**3. 여백은 그림 안에서 잡으세요.** 코드는 크기를 안 줄입니다.
슬라임을 칸보다 조금 작게 하고 싶으면 그림 자체에 투명 여백을 두세요.

> 들여오기 설정(Point 필터 · 압축 없음 · 밉맵 없음)은 **저절로** 맞춰집니다.
> Inspector 를 만지실 필요 없습니다. — `Assets/Editor/ArtImport.cs`

## 자리 목록

### 지형

| 이름 | 무엇 | 알아두실 것 |
|---|---|---|
| `wall.png` | 벽 = 돌 한 칸 | 위아래좌우로 이어 붙습니다. **네 변이 맞물리게** 그리세요 |
| `wall_top.png` | 돌 **윗면** | 🔴 "여기 딛고 설 수 있다"는 신호입니다. 가로로 납작한 띠 |
| `floor.png` | 빈 칸(공기) | 여기도 이어 붙습니다. 너무 눈에 띄면 안 됩니다 |

### 슬라임

| 이름 | 무엇 | 알아두실 것 |
|---|---|---|
| `head.png` | 머리 | 없으면 `body.png`도 안 쓰고 코드 그림으로 갑니다 |
| `body.png` | 몸 마디 | 머리와 같아도 됩니다 |
| `link.png` | 마디 **사이 이음매** | 🔴 몸이 끊겨 보이면 안 됩니다. `body` 굵기와 맞추세요 |
| `key.png` | 머리에 박힌 **열쇠** | 위아래로 긴 마름모. 번쩍임은 코드가 입힙니다 |

### 물건

| 이름 | 무엇 | 알아두실 것 |
|---|---|---|
| `food.png` | 먹으면 몸이 느는 조각 | |
| `star.png` | 별 | 🔴 먹어도 몸이 **안** 늡니다. 조각과 확실히 달라야 합니다 |
| `core.png` | 열쇠 **구멍**(심) | 머리가 여기서 끝나야 이깁니다. `key.png`와 짝이 맞게 |
| `pad.png` | 받침대 | 🔴 홈이 **아닙니다.** 여기 놓은 몸은 계단만 됩니다 |

## 아직 코드가 그리는 것 (그림 안 받습니다)

- **홈 틀** — 덩어리 모양이 판마다 달라서, 바깥선을 따라 레일을 두르고 있습니다.
  그림으로 바꾸려면 이웃 여부에 따라 **16가지**가 필요합니다. 나중에 하죠
- **처마 밑 그늘 · 격자선 · 빨려드는 연출 · UI**

## 색 규칙 (그림 그리실 때 참고)

지금 화면이 쓰는 층입니다. 안 지키셔도 되지만, 지키면 **색만으로 읽힙니다.**

```
초록 돌      #2f3e37   지형 — 못 움직이는 것
밝은 윗면    #627e70   딛고 설 수 있는 면
초록 슬라임  #8dceb0   나
놋쇠 틀      #c99a46   홈 — 목표
주황 조각    #f38a04   먹는 것
금빛 심/열쇠 #f0c05a   열쇠와 자물쇠
```

🔴 **지금 돌·홈·슬라임이 전부 초록입니다.** 그래서 목표와 나를 가르는 일을
테두리 굵기가 혼자 떠맡고 있습니다. 그림 그리실 때 **홈 쪽을 다른 색으로**
빼주시면 이 문제가 풀립니다. (참고 주신 그림이 딱 그렇게 돼 있었습니다 —
돌도 초록 슬라임도 초록인데 **홈만 놋쇠**)
